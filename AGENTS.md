# Інструкції для роботи з бізнес-аналітиком

Це навчальна версія публічного сайту Фундації Лятошинського. Відвідувачі знайомляться з життям і творчістю Бориса Лятошинського, знаходять наукові праці й архівні матеріали та дізнаються, як долучитися до роботи Фундації. На воркшопі бізнес-аналітик використовує ці сценарії, щоб описувати вимоги й формулювати критерії приймання.

## Основні сторінки

| Сторінка | Маршрут українською | Для чого відвідувач її відкриває |
| --- | --- | --- |
| Головна | `/uk` | Познайомитися з Фундацією, побачити добірку новин і подій та обрати розділ. |
| Про Фундацію | `/uk/about-us` | Дізнатися, хто заснував Фундацію, яка її місія та чим вона займається. |
| Життєпис | `/uk/biography` | Простежити події життя композитора за роками. |
| Творчість | `/uk/artistry` | Знайти музичний твір Лятошинського в каталозі. |
| Дослідження та наукові роботи | `/uk/research` | Знайти наукову працю про композитора або його творчість. |
| Архів | `/uk/archive` | Знайти архівний фонд за назвою або номером. |
| Архівний фонд | `/uk/archive/[fund]` | Переглянути приклад опису архівного фонду та перелік документів. Для різних номерів фонду демоверсія показує той самий опис і перелік. |
| Архівна справа | `/uk/archive/[fund]/[case]` | Звірити шифр і дати справи та переглянути перелік її документів. |
| Новини, події та медіа | `/uk/news` | Прочитати новини Фундації та знайти згадки про неї в медіа. |
| Співпраця | `/uk/cooperation` | Ознайомитися з форматами партнерства та обрати спосіб співпраці. |
| Підтримати Фундацію | `/uk/support-us` | Дізнатися про способи допомоги та знайти відповіді на запитання про підтримку. |
| Фундація під час війни в Україні | `/uk/war-in-ukraine` | Дізнатися про волонтерські ініціативи, які підтримує Фундація. |
| Контакти | `/uk/contacts` | Переглянути демонстраційні номер телефону й електронну адресу або заповнити форму звернення. У початкових даних немає посилань на соцмережі. |
| Політика конфіденційності | `/uk/privacy-policy` | З’ясувати, які дані збирає сайт і як їх використовує. |
| Умови користування сайтом | `/uk/terms` | Перевірити правила користування сайтом і його матеріалами. |

## Як описувати вимоги

- Почни зі сторінки в `app/[lang]/` і перевір, що бачить та може зробити відвідувач. Назви елементів інтерфейсу звіряй з українським словником `i18n/messages/uk.json`.
- Позначай окремо поточну поведінку, запропоновану зміну й відкриті питання. У критерії приймання вкажи початкові умови, дію відвідувача та результат, який можна перевірити.

## Конвенції

- Основна мова сайту й навчальних специфікацій — українська (`uk`). Сайт також підтримує англійську (`en`).
- Для нового коду використовуй TypeScript (`.ts` або `.tsx`) та іменовані експорти. Використовуй `export default` лише там, де цього вимагає Next.js, зокрема для компонентів сторінок і макетів у `page.tsx` та `layout.tsx`.

## Дані навчального середовища

Кожен запуск через `npm run dev` або `npm start` створює нову тимчасову базу MongoDB і заповнює її демонстраційними даними. Зміни в базі діють до зупинки застосунку. Для повторного тесту після перезапуску відтвори потрібні дані або використай початковий набір із `scripts/seed-memory-mongo.js`.
